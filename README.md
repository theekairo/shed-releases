# Shed

Расписание занятий группы ПР126 для Android и iOS.

| Платформа | Скачать | Установка |
| --- | --- | --- |
| Android | [Shed.apk](https://github.com/theekairo/shed-releases/releases/latest/download/Shed.apk) | Обычная установка APK |
| iOS 26+ | [Shed.ipa](https://github.com/theekairo/shed-releases/releases/download/ios-v1.1.0/Shed.ipa) | [Подпись и установка IPA](INSTALL-iOS.md) |

Все версии и список изменений — в [релизах](https://github.com/theekairo/shed-releases/releases).

## iOS

Расписание из Дневник.ру, замены, выбор подгруппы и виджет экрана блокировки. Светлая, тёмная и системная темы. Последнее расписание остаётся доступным без интернета.

IPA нужно подписать своим Apple-аккаунтом или сертификатом. Готовый файл не привязан к конкретному iPhone. Для работы виджета при установке необходимо сохранить расширение `ShedWidget`.

## Обновления

`update.json` используется Android-приложением, `update-ios.json` — iOS-приложением. Версии для разных платформ выпускаются отдельно.

В этом репозитории публикуются готовые сборки и описания релизов. Исходников приложения здесь нет.
