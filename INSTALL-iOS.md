# Установка Shed на iPhone

Нужна **iOS 26 или новее**.

1. Скачай `Shed.ipa` из [релиза для iOS](https://github.com/theekairo/shed-releases/releases/tag/ios-v1.1.0).
2. Подпиши IPA своим Apple-аккаунтом или сертификатом в программе, которой пользуешься для установки приложений вне App Store.
3. Сохрани расширение `ShedWidget` при установке — оно нужно для виджета экрана блокировки.
4. Открой Shed, выбери подгруппу и войди в Дневник.ру.

Сам по себе скачанный IPA не устанавливается нажатием в «Файлах». В релизе нет персонального профиля разработчика; срок действия установленного приложения зависит от твоей подписи.

## Виджет

Удерживай экран блокировки → «Настроить» → область виджетов → **Shed**. Доступны прямоугольный и круглый варианты. Нажатие на виджет открывает расписание.

Приложение и расширение должны быть подписаны одной командой с общей группой Keychain `TEAM_ID.com.example.ShedIOS.widgetdata`, где `TEAM_ID` — идентификатор твоей команды подписи. Он определяется приложением автоматически. Если программа подписи удаляет расширения или общие группы Keychain, виджет работать не будет.

Установка и виджет проверены через xtool на iPhone 13. Другие программы подписи отдельно не проверялись.

## Обновление

Устанавливай новую версию поверх предыдущей с тем же Apple-аккаунтом и идентификатором приложения. Так сохранятся настройки и вход. После смены подписи может потребоваться повторный вход в Дневник.ру.

Для проверки загрузки в релизе есть `SHA256SUMS.txt`.
